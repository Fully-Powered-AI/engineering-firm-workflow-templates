# Project experience sheet: an invented example

*Illustrative example with invented data.* Firm E, the parks authority, City M, Firm Q, Firm G, Contractor C, the project and every record named below are invented. Firm E is an invented 40-person civil and structural engineering firm. Its proposal lead is answering a request for qualifications from City M and wants to show one finished footbridge project.

The inputs come first, in full, so the template can be run on them. The output follows.

## The inputs

### The request and the settings

```
Proposal: Response to City M's request for qualifications, rehabilitation
  of the Riverside Path Bridge.
Requirements to show with an example project:
  R1. A pedestrian bridge replacement or rehabilitation project.
  R2. Completed within the last seven years.
  R3. The consultant's role and the scope it performed.
  R4. Experience with a historic or heritage-designated structure.
Firm name on the sheet: Firm E.
Project principal role: Principal-in-charge. Marketing role: Marketing lead.
Length limit: default. Requester: proposal lead. Today's date: 10 November 2026.
```
